How the cables make music

In the patch lattice, every time two dots fuse into a cable, that cable plays one note. Nobody composes anything. The music comes from three rules: positions map to a scale that cannot clash, each note is a tiny synth built from a few oscillators, and everything automatic runs on one tempo clock.

Every sound on this page is generated live with the Web Audio API, using the same numbers as the source code. Tap anything to start the audio.

A note fires when a cable closes

Each diagonal in the grid has a spring value E from 0 (two separate dots) to 1 (a fat cable). When E rises past 0.52 the cable plays its note. It cannot fire again until E falls below 0.38, so a cable wobbling around the threshold does not stutter. Two more limits keep a fast swipe from turning into noise: at most one note per animation frame, and a minimum gap between notes of 140ms for Mist and 50ms for the other voices.

if (!onState[k] && E[k] > 0.52) { onState[k] = 1; playVoice(i, j); }
else if (onState[k] && E[k] < 0.38) onState[k] = 0;

Where you are decides the pitch

The cell's column and row pick a step on a ladder of 15 notes: deg = (i + (rows − j) × 2) mod 15. Moving right climbs one step; moving up climbs two. The ladder is G minor pentatonic over three octaves, starting at G2, 98 Hz. Pentatonic scales have no semitone neighbours, so any two notes sound fine together, in any order. That is why a random swipe still sounds like a phrase.

Drag across the dots. Then switch to every semitone and drag the same path to hear the clashes the scale removes.

Each note is a small synth

A voice is a recipe of layers: oscillators make the raw tone, a filter shapes its brightness, and a gain envelope shapes its loudness over time. Switch the layers below off and on to hear what each one adds.

One room for every note

All voices feed a shared bus at gain 0.16, then a lowpass at 2200 Hz that takes the harsh top off. A 270ms delay with 34% feedback repeats each note a few times, and Mist also sends into a 3.6 second reverb. The reverb has no recorded room: its impulse response is white noise, smoothed by a one-pole filter and faded out with (1 − n/len)^2.6. Shared effects are what make separate notes sound like one piece.

These switches change the room for every demo on the page. Play with all three off, then turn them on one at a time.

One clock keeps it in time

The generators (rain, the self-patcher, signal pulses and the sequencer) all count beats from the same tempo, 108 bpm by default, so an eighth note is 278ms. The sequencer moves a playhead one column per eighth note and plays up to three patched cables in that column, skipping the row under each one it plays. What you draw becomes the pattern. Signal pulses add a second voice on the quarter note: one starts on a random inked cable each beat and plays a note at every jack it reaches.

One difference from the source: the source fires each note on the animation frame where the beat lands, so a note can be up to one frame (16.7ms) late. This demo schedules notes 100ms ahead on the audio clock, which keeps them exact.

Making music like this yourself

  1. Pick a scale with no clashes. Pentatonic or a single chord. Then nothing a person does can sound wrong.
  2. Map space to pitch. Position, speed or size picks the step on that scale. People hear their gesture in the melody.
  3. Keep notes short and few. Fast attacks, decays under three seconds, a minimum gap between notes, and a cap per frame.
  4. Give the notes small imperfections. Two oscillators a few cents apart, a random velocity, an occasional octave or fifth.
  5. Put everything in one room. One bus, one filter, one delay, one reverb.
  6. Run every automatic part off one clock. Quantise generators to beats so they line up with each other.
